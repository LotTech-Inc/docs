The Manage Users page is your central control point for every account on your LotTech Voice platform. From here you can see all team members, add new users, filter by role, review deactivated accounts, and open any user's detail page to update their settings. Access to this area is restricted to users with the **Admin** role.

## Accessing User Management

Navigate to **Admin** in the left sidebar, then select **Users**. If you do not see the Admin section in your sidebar, your account does not have the Admin role — contact your platform administrator to request access.

## Viewing and Searching Users

The Users page lists every account in your platform. Each row displays the user's name, email address, assigned roles, and the date they were created and last signed in.

To find a specific user, type in the **search bar** at the top of the list — you can search by name or email address. To include deactivated accounts in the list, enable the **Show Deleted** toggle. Deleted users appear highlighted so you can distinguish them from active accounts at a glance.

## Filtering by Role

Use the **role filter** dropdown to narrow the list to a specific role type. Available filters include:

- Administrator
- Rooftop Admin
- Parts Manager
- Cosmetics Manager
- Service Manager
- Commerce Manager
- Rental Manager
- Email Manager

## Creating a New User

Click **Add User** at the top right of the Users page to open the user onboarding wizard. The wizard walks you through three steps:

<Steps>
  <Step title="Personal information">
    Enter the new user's first name, last name, email address, and a password for their account. A phone number is optional.
  </Step>
  <Step title="Role selection">
    Select one or more roles for the user. You can assign any combination of roles — for example, a team member might hold both Parts Manager and Service Manager at the same rooftop.
  </Step>
  <Step title="Rooftop assignment">
    If the selected role is scoped to a rooftop (such as Parts Manager or Rental Manager), choose the rooftop this user will work in. Only rooftops with the relevant product enabled appear in the list.
  </Step>
</Steps>

When you complete the wizard, the user account is created immediately and the new user can sign in with the credentials you provided.

<Note>
  Roles that are scoped to a rooftop — such as Parts Manager or Service Manager — require you to select a rooftop in step three. Platform-wide roles like Administrator do not require a rooftop assignment.
</Note>

## Opening a User's Detail Page

Click any row in the Users list to open that user's detail page. From there you can review their full profile, update their settings, and manage their role and rooftop assignments.

<Warning>
  Deleting a user immediately revokes their access to the platform. Use the **Delete User** action on a user's row only when you are certain you want to remove that account. Deleted users remain visible in the list when **Show Deleted** is enabled.
</Warning>
