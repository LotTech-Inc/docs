The Manage Users page is your central control point for every account in your LotTech Voice platform. From here you can see all active staff members, invite new managers, update roles and rooftop assignments, and review deactivated accounts. Access to this area is restricted to users with the **Admin** role.

## Accessing User Management

Navigate to **Admin** in the left sidebar, then select **Users**. The full URL is `/dashboard/admin/users`. If you do not see the Admin section in your sidebar, your account does not have the Admin role — contact your platform administrator to request access.

## Viewing Users

The Users page lists every active account in your platform. Each row displays the user's name, email address, assigned role, and the rooftops they have access to.

To find a specific user, use the **search bar** at the top of the list — you can search by name or email address. To include deactivated accounts in the list, toggle **Show Deleted** on. Deleted users appear with a visual indicator so you can distinguish them from active accounts at a glance.

## Creating a New User

<Steps>
  <Step title="Open the onboarding form">
    Click **Create Manager** at the top right of the Users page.
  </Step>
  <Step title="Fill in user details">
    Enter the new user's first name, last name, and email address in the User Onboarding Form.
  </Step>
  <Step title="Submit the form">
    Click **Submit**. The new user immediately receives an invitation email with a link to set their password and log in.
  </Step>
</Steps>

<Note>
  All new users are created with the **Manager** role by default. If you need to grant Admin access, save the form first and then edit the user's role from their detail page.
</Note>

## Editing a User

Click on any user's name or row in the list to open their detail page. From the detail page you can update:

- **Name** — first and last name as it appears across the platform
- **Role** — Manager or Admin
- **Assigned Rooftops** — which dealership locations the user can access

Changes save as soon as you confirm them on the detail page. There is no separate save button — each field commits on update.

## Assigning Rooftops

A user can only view and work in the rooftops they are assigned to. From the user's detail page, scroll to the **Rooftop Access** section to add or remove rooftop assignments. Adding a rooftop gives the user immediate access to that location's dashboard, activity feed, and settings (within the limits of their role). Removing a rooftop revokes access the next time the user navigates or refreshes.

<Warning>
  Changing a user's role takes effect immediately — there is no confirmation delay. If you remove the Admin role from a user who is currently logged in, they are logged out of all Admin views and redirected to the standard dashboard on their next page load. Make sure you intend the change before saving.
</Warning>
