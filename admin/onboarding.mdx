The Onboarding hub is where you go to expand your LotTech Voice platform — adding new team members, bringing new dealership locations online, and migrating existing dealer setups from your documentation. Whether you are standing up a single new rooftop or migrating a large group of locations, the tools here are designed to reduce manual data entry and get you operational as quickly as possible.

## Onboarding Hub

Navigate to **Admin** in the left sidebar, then select **Onboarding**. The full URL is `/dashboard/admin/onboarding`. The hub presents four tools:

| Tool | What it does |
|---|---|
| **Create Manager** | Invite a new user to the platform |
| **Create Rooftop** | Set up a new dealership location manually |
| **Onboard from PDF** | Create a new rooftop from a dealer setup document |
| **Update from PDF** | Update an existing rooftop's config from a revised document |

## Create a New Manager

Use this flow to invite a new team member to your platform.

<Steps>
  <Step title="Click Create Manager">
    Select **Create Manager** from the Onboarding hub.
  </Step>
  <Step title="Enter user details">
    Fill in the new user's first name, last name, and work email address.
  </Step>
  <Step title="Submit the form">
    Click **Submit**. The new user receives an invitation email immediately with a link to set their password. They are created with the **Manager** role by default — you can update their role from Admin &gt; Users if needed.
  </Step>
</Steps>

## Create a New Rooftop

Use this flow to manually set up a new dealership location from scratch.

<Steps>
  <Step title="Click Create Rooftop">
    Select **Create Rooftop** from the Onboarding hub.
  </Step>
  <Step title="Fill in the Rooftop Onboarding Form">
    Enter the dealership name, full street address, primary and any secondary phone numbers, and select which modules to enable — Parts, Cosmetics, Service, and/or Rental.
  </Step>
  <Step title="Submit the form">
    Click **Submit**. The rooftop is created and available in Admin &gt; Rooftops immediately.
  </Step>
  <Step title="Complete setup in Rooftop Settings">
    After creation, navigate to the rooftop's settings page to configure business hours, routing rules, module-specific options, and team assignments.
  </Step>
</Steps>

## Onboard from PDF

If you have a standard dealer setup document, you can skip most of the manual form-filling by uploading it directly. The AI parser reads the document and automatically populates the rooftop configuration for your review.

<Steps>
  <Step title="Click Onboard from PDF">
    Select **Onboard from PDF** from the Onboarding hub.
  </Step>
  <Step title="Upload your dealer setup document">
    Choose the PDF file from your device. The parser accepts standard dealer onboarding and facility documents.
  </Step>
  <Step title="Review the parsed data">
    LotTech Voice displays the information it extracted from the document — dealership name, address, contact details, and detected services. Review each field and correct anything that was misread.
  </Step>
  <Step title="Confirm to create the rooftop">
    Click **Confirm** to create the rooftop with the reviewed data. You can continue refining the configuration in Rooftop Settings afterward.
  </Step>
</Steps>

<Info>
  The PDF parser is designed to work with standard dealer setup and facility documents. It extracts dealership name, address, contact information, and available services automatically. Complex or non-standard document layouts may require more manual corrections in the review step.
</Info>

## Update from PDF

Use this flow when a rooftop's configuration has changed and you have an updated dealer document to reflect those changes — such as new phone numbers, updated hours, or added service lines.

<Steps>
  <Step title="Click Update from PDF">
    Select **Update from PDF** from the Onboarding hub.
  </Step>
  <Step title="Select the rooftop to update">
    Choose the existing rooftop you want to apply the update to from the dropdown list.
  </Step>
  <Step title="Upload the updated PDF">
    Upload the revised dealer setup document.
  </Step>
  <Step title="Review the proposed changes">
    LotTech Voice highlights the differences between the current rooftop configuration and the data parsed from the new document. Review each change carefully before applying.
  </Step>
  <Step title="Confirm the update">
    Click **Confirm** to apply the reviewed changes to the rooftop's configuration.
  </Step>
</Steps>

<Tip>
  When migrating multiple dealership locations at once, use the **Onboard from PDF** flow for each location rather than filling out forms manually. Even if the parsed data needs some corrections, it is significantly faster than entering every field by hand — especially for large dealer groups with many locations.
</Tip>
