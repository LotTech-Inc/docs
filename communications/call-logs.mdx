Call Logs give you direct access to the raw recordings and transcript files generated by your AI voice agent for every call session. Whether you need to audit a conversation, verify what was said, or download a recording for a service dispute, the Logs section keeps every file organized and ready to retrieve.

## Navigating Call Logs

Go to **Logs** in the left sidebar to open the Call Logs section. You'll see a list of **call session folders** sorted in reverse-chronological order — the most recent calls appear at the top.

<Note>
  Access to Call Logs requires the **Communications module** permission. If you don't see **Logs** in your sidebar, ask your LotTech administrator to verify your role permissions.
</Note>

Each row in the list represents one call session. The folder name is converted to a human-readable date and time so you can identify calls at a glance.

## Folder Structure

Every call session is stored in its own folder. Folder names follow this format:

```
{channel}_{YYYYMMDD}_{HHMMSS}_{sessionId}
```

For example: `call_20250616_202707_a3f9c2` or `sms_20260327_204821_491b56a3`

| Segment | Description |
|---|---|
| `channel` | The channel for the session — `call` for voice, `sms` for text. |
| `YYYYMMDD` | The date of the session (year, month, day — no separators). |
| `HHMMSS` | The session start time (hour, minute, second — no separators). |
| `sessionId` | A unique identifier for the session. |

The platform displays each folder as a formatted local date and time, so you don't need to parse the raw name yourself.

Inside each folder you'll find:

- **Recording file** (`.wav`) — the audio of the voice call
- **Transcript file** (`.txt`) — the text conversation from the session

<Info>
  Call Logs are stored on a per-session basis and reflect the raw session data. They are separate from the **Interactions** view, which presents structured metadata — duration, direction, requests created, and so on — derived from the same session. Use Interactions for day-to-day management and Call Logs when you need the source file.
</Info>

## Viewing a Recording

<Steps>
  <Step title="Open the session folder">
    Click any folder in the Logs list to expand it and see its files.
  </Step>
  <Step title="Select the recording file">
    Click the **Recording** (`.wav`) file. An in-browser audio player will open so you can listen without downloading.
  </Step>
  <Step title="Scrub or replay">
    Use the player controls to pause, scrub to a specific moment, or replay the recording as needed.
  </Step>
</Steps>

## Viewing a Transcript

Click the **Conversation** (`.txt`) file inside a session folder to open the transcript in a **chat-bubble view**. Each turn is displayed as a labeled message bubble:

- **Caller** turns appear on the left
- **Agent** turns appear on the right

This layout makes it easy to follow the flow of the conversation and identify the exact exchange you're looking for without reading a wall of text.

## Downloading Files

You can save recordings and transcripts to your computer directly from the Logs section.

<Steps>
  <Step title="Open the session folder">
    Navigate to the call session you need.
  </Step>
  <Step title="Select the file">
    Click the recording or transcript file to select it.
  </Step>
  <Step title="Click Download">
    Click the **Download** button in the content viewer toolbar. The file will save to your browser's default download location.
  </Step>
</Steps>

<Tip>
  Download both the recording and transcript for the same session if you're compiling documentation for a service dispute or quality review — having both formats together makes review faster.
</Tip>

## Searching Folders

Use the **search bar** at the top of the Logs page to filter the folder list by name. Type any part of a date, time, or session ID to narrow the results to matching sessions.

To refresh the folder list after new calls have come in, click the **Refresh** button in the toolbar. The list will reload and any new sessions will appear at the top.
