Call Logs give you direct access to the raw recordings and transcript files generated by your AI voice agent for every call session. Whether you need to audit a conversation, verify what was said, or download a recording for a service dispute, the Logs section keeps every file organized and ready to retrieve.

## Navigating Call Logs

Go to **Logs** in the left sidebar to open the Call Logs section. You'll see a list of **call session folders** sorted in reverse-chronological order — the most recent calls appear at the top.

<Note>
  Access to Call Logs requires the **Communications module** permission. If you don't see **Logs** in your sidebar, ask your LotTech administrator to verify your role permissions.
</Note>

Each row in the list represents one call session. The folder name tells you at a glance when the call happened and which session it belongs to.

## Folder Structure

Every call session is stored in its own folder. Folder names follow this format:

```
{prefix}_{date}_{time}_{sessionId}
```

For example: `lottech_2024-11-14_09-32-17_a3f9c2`

| Segment | Description |
|---|---|
| `prefix` | Your rooftop's configured identifier. |
| `date` | The date of the call in `YYYY-MM-DD` format. |
| `time` | The call start time in `HH-MM-SS` format. |
| `sessionId` | A unique identifier for the session. |

Inside each folder you'll find:

- **Recording file(s)** — the audio of the call
- **Transcript file(s)** — the text representation of the conversation

<Info>
  Call Logs are stored on a per-call basis and reflect the raw session data. They are separate from the **Interactions** view, which presents structured metadata — duration, direction, requests created, and so on — derived from the same session. Use Interactions for day-to-day management and Call Logs when you need the source file.
</Info>

## Viewing a Recording

<Steps>
  <Step title="Open the session folder">
    Click any folder in the Logs list to expand it and see its files.
  </Step>
  <Step title="Select the recording file">
    Click the audio recording file. An in-browser audio player will open so you can listen without downloading.
  </Step>
  <Step title="Scrub or replay">
    Use the player controls to pause, scrub to a specific moment, or replay the recording as needed.
  </Step>
</Steps>

## Viewing a Transcript

Click the transcript file inside a session folder to open the conversation in a **chat-bubble view**. Each turn is displayed as a labeled message bubble:

- **Caller** turns appear on the left
- **Agent** turns appear on the right

This layout makes it easy to follow the flow of the conversation and identify the exact exchange you're looking for without reading a wall of text.

## Downloading Files

You can save recordings and transcripts to your computer directly from the Logs section.

<Steps>
  <Step title="Open the session folder">
    Navigate to the call session you need.
  </Step>
  <Step title="Locate the file">
    Find the recording or transcript file you want to download.
  </Step>
  <Step title="Click the download button">
    Click the **Download** icon next to the file. The file will save to your browser's default download location.
  </Step>
</Steps>

<Tip>
  Download both the recording and transcript for the same session if you're compiling documentation for a service dispute or quality review — having both formats together makes review faster.
</Tip>

## Filtering Logs

Use the **date filter** in the toolbar at the top of the Logs page to narrow the list to a specific date range. Enter a start date, an end date, or both to scope the results.

Date filtering is applied via search parameters in the URL, so you can bookmark or share a pre-filtered Logs view with a teammate by copying the URL after applying your filter.
