**For rooftop admins.** Configure how the receptionist sounds at your dealership from **Rooftop Settings → Overview → Voice Configuration**.

If voice service is not active for your rooftop, contact LotTech support about activation.

## Set the agent name

Edit **Agent Name** and save the field. Use the name you want the receptionist to use with callers.

## Choose and preview a voice

1. Select a **Voice** from the available choices.
2. Adjust **Speed** and **Room Echo** if needed.
3. Use **Voice Tester** to listen to the draft settings.
4. Select **Save changes** when you are ready to use them.

<Note>
  Previewing a voice does not save it. Select **Save changes** to apply your voice, speed, echo, and pronunciation edits.
</Note>

## Adjust pronunciations

Use **Pronunciations** for names or words that need a particular pronunciation. Add the word and how it should sound, preview it with **Voice Tester**, then save your changes.

## Check phone numbers

The **Phone Number** in Voice Configuration shows the number assigned to your receptionist. Contact LotTech support if that assigned number needs to change.

You can update your dealership's department transfer numbers separately. See [Phone numbers and transfers](/rooftop/phone-and-transfers).
